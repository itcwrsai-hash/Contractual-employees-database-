QR code for checking gate passes

Every gate pass gets a QR code on the back. Scanning it with any phone camera opens a page showing, with the photo, whether the pass is valid today – so security staff can spot fake, expired or withdrawn cards. The page shows only what is on the card, never Aadhaar, address or mobile number. The phone must be connected to the workshop network (Wi-Fi).
